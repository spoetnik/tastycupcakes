Great teams act interdependently to achieve product outcomes. That doesn’t happen by accident. It takes deliberate effort. By proactively determining how teams depend on each other, agreements can be made on the “give and take” required to improve teamwork. Doing so strengthens team partnerships and customer relationships. Ultimately, this leads to better product outcomes and makes work more joyous.

The MatchUp Canvas is a tool you can freely use to facilitate great teamwork.

This link provides you a pdf which contains both the MatchUp Canvas and detailed instructions for facilitating using this tool.

For background information about team interdependence, read this blog post.
